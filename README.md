## Built with

This is a static site using semantic HTML, CSS, and vanilla JavaScript. It requires no build step, package manager, backend, or third-party JavaScript dependencies. Portfolio media is stored in `assets/`.

## Run locally

From the repository root, start a local web server:

```bash
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000).

## Publish with GitHub Pages

1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose the `main` branch and the `/(root)` folder, then save.
4. After GitHub finishes publishing, visit [https://radhikabapure25.github.io/radhikabapure25/](https://radhikabapure25.github.io/radhikabapure25/).

The site entry point is `index.html`; the image, video, and logo assets use relative paths so they work on the project Pages URL.

## Image privacy

The page discourages casual image saving through browser context-menu and drag protections. Those are not access controls: images published in a public repository or on a public website can still be downloaded or captured. Do not publish an image unless you are comfortable with it being publicly accessible.
